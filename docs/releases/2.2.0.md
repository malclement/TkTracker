# TkTracker 2.2.0

## Install

Unzip `TkTracker-2.2.0.zip` and move `TkTracker.app` to `/Applications`. Then run
`xattr -dr com.apple.quarantine /Applications/TkTracker.app` in Terminal, or open the
app once and choose **Open Anyway** in System Settings › Privacy & Security. This is
needed once, because the build is ad-hoc signed rather than notarized by Apple. It
runs as a menu bar app: look for the chart icon in the status bar.

## Room for 50 agents

- **Up to 50 agents per project.** A project's workshop now seats up to 50 agents, up from 12. Session leads get desks before subagents. Anyone beyond 50 is counted on a "+N" plaque on the nameplate, and everyone stays listed in the session list.
- **Rooms grow in both directions.** A building adds desk rows as well as length along the street, so a big team fills a near-square room rather than a long strip. Desks never move as a room grows.
- **Places to rest.** Deep rooms get more couches along the side wall, so idle agents in big teams sit down instead of standing at their desks.
- **A tidy street.** Every door opens onto the sidewalk. A shallow building next to a deep one gets a back garden.

With a 50-agent team the whole-lot view zooms out to fit. Follow that project to see it at full size.

## Requirements and limitations

Requires macOS 15 or later. Shortcuts actions are not supported in this ad-hoc build: macOS rejects them without a Developer ID.

App version 2.2.0, build 13. Supports Apple Silicon and Intel. Usage archives from 2.x are kept as they are.
