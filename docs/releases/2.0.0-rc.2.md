# TkTracker 2.0.0 RC2 — Claude session detection

This preview fixes Claude Code sessions missing from Floating Workshops on Macs outside UTC.

- Interpret Claude's process start timestamp in UTC so live sessions are correctly recognized, while still rejecting stale metadata and reused process IDs.
- Find new session transcripts in project paths containing punctuation or Unicode before the usage scan finishes.
- Add regression coverage for process identity, transcript discovery and session closure.

App version 2.0.0, build 8. Requires macOS 15 or later; the download supports Apple Silicon and Intel.

This is an ad-hoc signed preview, without Developer ID signing or Apple notarization. macOS may block normal opening. Stable 1.5.1 remains the latest production release. Shortcuts execution remains unverified on a signed release build.

Includes the Floating Workshops, account, pricing and reporting features from RC1. Usage archives and provider configuration are unchanged.
