# TkTracker 2.3.0

## Install

Unzip `TkTracker-2.3.0.zip` and move `TkTracker.app` to `/Applications`. Then run
`xattr -dr com.apple.quarantine /Applications/TkTracker.app` in Terminal, or open the
app once and choose **Open Anyway** in System Settings › Privacy & Security. This is
needed once, because the build is ad-hoc signed rather than notarized by Apple. It
runs as a menu bar app: look for the chart icon in the status bar.

## A clearer Overview

- **Spend leads.** The API-equivalent value takes half the headline row, in larger type. Beside it, a badge shows the change against the previous period of the same length, or against yesterday by this hour on the Today view.
- **One place for the cache.** The cache hit rate tile is gone. The Prompt cache card shows the same figure with the money it saved.
- **Chart first.** The spend chart comes straight after the headline, then the model breakdown. Accounts, quotas and budgets follow.
- **Quotas and budgets fit in.** Accounts sit side by side. Quota and budget bars turn amber, orange then red as they fill, and a quota reading more than five minutes old carries a "stale" badge.
- **Quieter notes and chart.** The pricing coverage note is a banner, amber only when totals are partial. Date labels are grey, y-axis ticks read "$0 / $50 / $100", an empty range says "No usage in this range", and models with no spend no longer appear in the model share list.

## Requirements and limitations

Requires macOS 15 or later. Shortcuts actions are not supported in this ad-hoc build: macOS rejects them without a Developer ID.

App version 2.3.0, build 14. Supports Apple Silicon and Intel. Usage archives from 2.x are kept as they are.
