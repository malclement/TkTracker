# TkTracker 2.3.1

## Install

Unzip `TkTracker-2.3.1.zip` and move `TkTracker.app` to `/Applications`. Then run
`xattr -dr com.apple.quarantine /Applications/TkTracker.app` in Terminal, or open the
app once and choose **Open Anyway** in System Settings › Privacy & Security. This is
needed once, because the build is ad-hoc signed rather than notarized by Apple. It
runs as a menu bar app: look for the chart icon in the status bar.

## Codex usage is accurate again

- **No more double counting.** Codex re-sends its last usage snapshot unchanged, often several times per turn. Each repeat was counted as a new call, which put Codex tokens and spend about 10% too high. Repeats are now skipped.
- **Forked subagents bill only their own work.** A forked subagent's file starts with a copy of its parent's history. That copy no longer becomes the subagent's identity, project or branch, and its usage is not counted a second time.
- **Codex sessions have titles.** Current Codex versions record prompts in a new format that the title reader missed, so Codex sessions showed no title. They now show their first prompt.
- **One-time re-scan.** On first launch, 2.3.1 re-reads your Codex sessions once to correct the stored totals. Codex numbers for past periods will be lower than in 2.3.0. That is the correction, not lost data. Sessions whose files Codex has already deleted or archived keep the totals earlier versions recorded.

## Workshops

- **Codex teams stay together.** Subagents a Codex session spawned, nested ones included, stay in its room after they finish, for as long as the session is loaded. Agents from earlier runs of a resumed session are left out.
- **Finished means finished.** A subagent Codex has let go of is never shown working. One that stopped mid-turn shows **Interrupted** and doesn't raise a "Needs you" alert nobody can answer.
- **Names you can tell apart.** Codex subagents go by the nickname Codex gives them, instead of an ID prefix their siblings shared.
- **Helpers aren't teammates.** `/review` runs and auto-approval reviews no longer join a session's team.
- **Busiest first.** When a team outgrows its room, the agents that are working or waiting on you get the desks.

## Requirements and limitations

Requires macOS 15 or later. Shortcuts actions are not supported in this ad-hoc build: macOS rejects them without a Developer ID.

App version 2.3.1, build 15. Supports Apple Silicon and Intel. Usage archives from 2.x are kept as they are.
