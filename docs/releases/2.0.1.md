# TkTracker 2.0.1

## Install

Unzip `TkTracker-2.0.1.zip` and move `TkTracker.app` to `/Applications`. Then run
`xattr -dr com.apple.quarantine /Applications/TkTracker.app` in Terminal, or open the
app once and choose **Open Anyway** in System Settings › Privacy & Security. This is
needed once, because the build is ad-hoc signed rather than notarized by Apple. It
runs as a menu bar app: look for the chart icon in the status bar.

## Pricing for new models

Usage on these models was tracked in tokens but counted as unpriced, so cost totals were partial. It is now priced from the vendors' published rates, including history recorded before this update.

- **Claude Opus 5.5**: $4 input, $20 output, $0.20 cache reads, $5 / $8 cache writes (5 min / 1 h) per million tokens. Fast mode is 2×.
- **GPT-6 Sol** and **GPT-6 Luna**, with cache-write, long-context and fast-mode rates.
- **GPT-5.5 Pro**, **GPT-5.4 Pro**, **GPT-5.2 Pro**, **GPT-5 Pro** and **GPT-5.5 Cyber**.

Codex's `codex-auto-review` model stays unpriced, because OpenAI publishes no rate for it. Its tokens are still counted, and totals say when they are partial. You can set your own rate in Settings › Pricing.

## Requirements and limitations

Requires macOS 15 or later. Shortcuts actions are not supported in this ad-hoc build: macOS rejects them without a Developer ID.

App version 2.0.1, build 10. Supports Apple Silicon and Intel. Usage archives from 2.0.0 are kept as they are.
