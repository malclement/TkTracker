# TkTracker 2.3.2

## Install

Unzip `TkTracker-2.3.2.zip` and move `TkTracker.app` to `/Applications`. Then run
`xattr -dr com.apple.quarantine /Applications/TkTracker.app` in Terminal, or open the
app once and choose **Open Anyway** in System Settings › Privacy & Security. This is
needed once, because the build is ad-hoc signed rather than notarized by Apple. It
runs as a menu bar app: look for the chart icon in the status bar.

## The newest Claude models are priced

Usage on these models was already counted in tokens, but had no price, so it was missing from every spend total and reported as "no price". 2.3.2 adds their rates:

| Model | Input | Output | Cache read | Cache write 5m / 1h |
| --- | --- | --- | --- | --- |
| Fable 5.2, Mythos 5.2 | $8 | $40 | $0.20 | $10 / $16 |
| Sonnet 5.5 | $2 | $10 | $0.10 | $2.50 / $4 |
| Haiku 5.5 | $0.10 | $0.50 | $0.01 | $0.125 / $0.20 |

Prices are USD per million tokens, checked against Anthropic's price list on November 16, 2026.

- **Past usage is repriced.** Totals for earlier days rise by the value of the usage that had no price. Nothing is re-scanned.
- **Fable 5.2 and Mythos 5.2 fast mode** is priced at twice the standard rate.
- **Haiku 5.5 long prompts.** A request whose prompt is over 100,000 tokens costs five times the standard rate on every token type, as Anthropic bills it.

## Requirements and limitations

Requires macOS 15 or later. Shortcuts actions are not supported in this ad-hoc build: macOS rejects them without a Developer ID.

App version 2.3.2, build 16. Supports Apple Silicon and Intel. Usage archives from 2.x are kept as they are.
