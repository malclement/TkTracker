# TkTracker 2.0.0

## Floating Workshops

Follow your agents in a native 3D scene. Each loaded session has a floating workshop with an animated avatar, with attached platforms for subagents. A focused view keeps the current workshop readable; All islands shows the wider session overview.

- Switch sessions and inspect every subagent from the persistent team list.
- Distinguish working, tool use, waiting for agents, waiting for input, idle, completed and interrupted states.
- Drag to orbit, zoom, or use Fit to frame the whole workshop and team.
- Filter by project or provider and explore a clearly labeled demo.
- Islands appear when sessions are detected and leave when closure is reliably observed. Idle time and turn completion do not close a session.

## Also new since 1.5.1

- Account profiles, independent subscription plans and optional Codex quota refresh.
- Expanded model pricing, cache and context pricing, and visible partial estimates.
- Custom date filters, saved views, comparisons, session details and branch history.
- Budgets, forecasts, opt-in alerts, backups and metadata retention controls.
- More accurate request timestamps, timezone handling, deduplication and CSV export.

## Requirements and limitations

Requires macOS 15 or later. Workshop monitoring reads local provider activity while the page is open; it does not install hooks or change provider configuration.

Codex may keep a session loaded after its tab closes, so its island can remain until Codex releases it. Claude Code tracking requires local session metadata. Missing provider signals cannot reliably identify every approval or waiting state. See [workshop lifecycle details](https://github.com/malclement/TkTracker/blob/main/docs/workshops.md).

SwiftPM builds do not include Shortcuts metadata. End-to-end Shortcuts execution must be verified on the signed Xcode release candidate before claiming support.
