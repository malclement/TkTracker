# TkTracker 2.0.2

## Install

Unzip `TkTracker-2.0.2.zip` and move `TkTracker.app` to `/Applications`. Then run
`xattr -dr com.apple.quarantine /Applications/TkTracker.app` in Terminal, or open the
app once and choose **Open Anyway** in System Settings › Privacy & Security. This is
needed once, because the build is ad-hoc signed rather than notarized by Apple. It
runs as a menu bar app: look for the chart icon in the status bar.

## A calmer Workshops lot

- **Ground.** A softer meadow surrounds the lot. The lot has mowed stripes, a picket fence along the front, and continuous gravel paths from each door to the sidewalk. Rooms, trees, streetlamps and bushes cast shadows, and the street now runs past the edge of the view.
- **Gardens.** An empty slot on the lot becomes a flower bed with a bench. Trees are kept out of gardens, where they hid the room behind them.
- **Night.** Dark mode is a deeper night with warmer streetlamps. A room's ceiling light is on only while someone in it is working, needs you or is waiting on agents. An idle room stays dark.
- **Page.** The scene title sits on a panel, so it stays legible over the lawn. The info popover explains what each plumbob colour means. The footer counts agents that need you. The inspector no longer shows the state twice.
- Room nameplates draw K correctly. It used to read as an R.

## Requirements and limitations

Requires macOS 15 or later. Shortcuts actions are not supported in this ad-hoc build: macOS rejects them without a Developer ID.

App version 2.0.2, build 11. Supports Apple Silicon and Intel. Usage archives from 2.0.x are kept as they are.
